# prial-plugins

A Claude Code marketplace of plugins by [James Prial](https://github.com/JamesPrial/).

## Install

```
/plugin marketplace add JamesPrial/prial-plugins
```

Then `/plugin install <name>@prial-plugins` for any plugin below.

## Plugins

| Name | Description |
| --- | --- |
| [todo-log](https://github.com/JamesPrial/todo-log) | Captures TaskCreate/TaskUpdate tool usage and saves to timestamped history with a configurable storage backend (JSON or SQLite). |
| [version-control](https://github.com/JamesPrial/version-control) | Git operations and GitHub CLI agents for version-control workflows. |
| [security-hooks](https://github.com/JamesPrial/security-hooks) | PreToolUse hook that detects and blocks secrets in git commits. |
| [golang-workflow](https://github.com/JamesPrial/golang-plugin) | Go development workflow with TDD-first parallel agents, failure triage, and automated code-quality hooks. |
| [go-plugin-release](https://github.com/JamesPrial/go-plugin-release) | Cross-platform binary compilation and distribution pipelines for Go-based plugins. |
| [deep-research](https://github.com/JamesPrial/deep-research) | Parallel multi-agent web research with source archival and cited reports. |
| [bumper](https://github.com/JamesPrial/bumper) | Bump plugin semver, update files, tag, and push. |
| [openclaw-assist](https://github.com/JamesPrial/openclaw-assist) | Full lifecycle assistant for OpenClaw: installation, configuration, channel setup, security hardening, deployment, troubleshooting, and ongoing management of the self-hosted AI assistant hub. |
| [unraid-assistant](https://github.com/JamesPrial/unraid-assistant) | Manage Unraid servers via the GraphQL API. |
| [claudebot](https://github.com/JamesPrial/claudebot) | Discord bot brain with intelligent triage, persistent memory, and an organically evolving personality. |
